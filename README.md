## Safety and Ethics

- Use these commands only in systems you own or are explicitly authorized to test.
- Some examples intentionally delete or overwrite files because they were written for disposable challenge sandboxes. Read each warning before running a command.
- Challenge passwords and private keys are intentionally omitted. Retrieve current connection details by completing the official exercises.
- The notes are historical and may not match the latest challenge content or every operating system.
